# Crystal Ledger

Builds of the Crystal Ledger Dalamud plugin. Nothing else lives here.

To install, add this custom plugin repository in game (`/xlsettings` → Experimental → Custom Plugin Repositories):

```
https://raw.githubusercontent.com/rhyseverett94/crystal-ledger-plugin/main/repo.json
```

The plugin needs your own Crystal Market Ledger site address and key, entered in `/ledger`.
